# Casa Italia Cortina 2026

Documentazione tecnica per l'allestimento audio-video di Casa Italia presso la Galleria Farsetti, Cortina d'Ampezzo - Olimpiadi Invernali Milano-Cortina 2026.

## Contenuto

- **4 LED Wall** (3 interni + 1 esterno)
- **Regia video centralizzata** con 3 PC VMIX
- **Impianti audio** in tutte le aree
- **Telecamere PTZ** per collegamenti inter-house

La pagina web con il recap completo del progetto e' disponibile su GitHub Pages (quando il repository e' pubblico).
